Pasta para evidências (prints) da execução do sistema.

Instruções para capturar e salvar prints:
1. Rode o programa conforme README.
2. Para capturar a tela no Windows:
   - Alternativa rápida: pressione Alt+PrtSc (captura apenas a janela ativa) e cole no Paint (Ctrl+V) e salve como `sensor_alerta.png`.
   - Alternativa: use a Ferramenta de Recorte (Snipping Tool) e salve as imagens.
3. Sugestões de prints a salvar:
   - `sensor_alerta.png` -> Menu principal exibindo leitura de sensores e uma mensagem de alerta.
   - `propulsao_submenu.png` -> Submenu de controle de propulsão mostrando opções.
   - `status_completo.png` -> Resultado da opção de status completo (sensores + propulsão + missão).
4. Coloque os arquivos de imagem nesta pasta (`evidence/`) e inclua-os no commit/entrega.

Observação: eu não consigo criar as imagens automaticamente — você deve executar o programa localmente e salvar as capturas na pasta `evidence`.
